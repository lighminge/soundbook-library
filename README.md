# 聲書閣 SoundBook Pavilion (`soundbook-library`)

一套以「**數位有聲圖書館**」為核心理念打造的現代化跨裝置有聲書展演與館藏管理系統。系統深度整合 **Firebase Cloud Firestore (`soundbook-library-db`)** 即時雲端資料庫與 **Google 雲端硬碟 (Google Drive)** 影音媒體儲存空間，具備完善的權限控制、時間軸圖文多媒體同步展演、主講人名冊與類別標籤全域維護、登入與播放行為日誌統計分析，並支援自動化部署至 **GitHub Pages** 與 **Firebase Hosting**。

- **GitHub Pages 線上系統網址**：https://lighminge.github.io/soundbook-library/
- **Firebase Hosting 線上系統網址**：https://soundbook-library-db.web.app
- **原始碼儲存庫**：https://github.com/lighminge/soundbook-library.git

## 一、系統特色與架構總覽

- **古典圖書館人文美學**：以典藏深色胡桃木（`#261A13`）、溫潤羊皮紙卡片（`#FFFDF9`、`#FAF4E8`）與精裝書背視覺為基調，專為有聲閱讀營造優雅沉浸氛圍。全站採用響應式設計（RWD），在電腦、筆電、iPad 平板與各式智慧型手機上皆有最佳排版與操作體驗。
- **雙雲端混合架構 (Hybrid Cloud Storage)**：
  - **Firebase Cloud Firestore (`soundbook-library-db`)**：負責毫秒級即時同步所有館藏分類 (`categories`)、語音詮釋資料 (`audioItems`)、時間軸圖文字幕設定、主講人名冊 (`speakers`)、類別標籤登錄簿 (`audio_tags`)、自訂播放清單 (`playlists`)、系統使用者 (`users`)、登入畫面組態 (`login_screen_config`)、人員登入紀錄 (`login_logs`) 與播放統計日誌 (`play_logs`)。
  - **Google 雲端硬碟 (Google Drive)**：透過 Google Apps Script (GAS) 專屬後端代理腳本，安全儲存高音質語音檔、高解析封面圖與展演插圖。支援在網頁介面修改語音標題或插圖檔名時，**自動即時同步更新 Google Drive 中的實體檔案名稱**；刪除館藏時亦可連動安全清理雲端硬碟檔案。
- **跨裝置極速播放與雙重備援機制**：
  - 整合前端 **IndexedDB 本地媒體快取** 與 Firestore 分片備援機制 (`audioChunks`)。
  - 對於無法直接存取外連串流的行動裝置環境（如特定版本 iOS Safari / 阻擋跨域 Cookie 的瀏覽器），系統會自動透過分片備援或快取播放，確保零中斷、無延遲的聽書體驗。
- **零快取差異抗快取打包技術 (`gh-pages-cache-compat`)**：
  - 專案客製化 Vite 打包流水線，在執行 `npm run build` 時會自動進行多層資產雜湊別名處理，徹底解決 GitHub Pages 與靜態伺服器因瀏覽器硬取快取導致使用者看不到最新畫面的問題。

## 二、登入驗證與三層身分權限管理

系統入口提供 **「安全存取驗證（登入畫面）」**，具備防瀏覽器自動儲存填入、可自訂圖示與主標題之特點，並支援三種身分角色：

| 身分角色 | 權限範圍說明 |
| :--- | :--- |
| **1. 系統管理員 (`admin`)** | 具備全系統完整最高權限：可使用「館藏總覽」、「放映室」、「語音檔案庫」、「館藏資料管理」，並獨享上方工具列的 **「系統管理」** 專區（完整管理系統使用者帳號、檢視人員登入情況紀錄與圖表分析、維護登入畫面樣式、設定雲端連線，以及使用全館播放時數統計作業）。 |
| **2. 一般使用者 (`user`)** | 具備館藏編目、上傳與閱讀聽書權限：可瀏覽「館藏總覽」（全部館藏分類廳）、使用「放映室」（播放、展演與建立自訂播放清單）、進入「語音檔案庫」（上傳新音訊、錄音、編輯時間軸圖文與字幕），以及使用「館藏資料管理」（維護分類、主講人名冊與類別標籤）。 |
| **3. 訪客模式 (`guest`)** | 於登入畫面點擊 **「以訪客身份直接進入（免帳密）」** 即可進入系統。訪客僅能瀏覽與播放**管理員已開啟「開放訪客瀏覽 (`allowGuest`)」之館藏分類廳及其語音作品**；所有上傳、編輯、刪除、館藏資料管理與系統管理功能均自動隱藏並受到後端路由保護。 |

## 三、頂部導覽列與人員狀態顯示

- **靠左對齊與精緻大字體設計**：最左側為品牌標誌「**聲書閣**」，各功能分頁按鈕統一採用易讀字體 (`text-base sm:text-lg`) 與一致的典藏圖示，收合於深木色典藏標題列底圖內，確保在任何螢幕寬度下皆具備舒適的視覺層次。
- **功能按鈕排列順序（由左至右）**：
  1. **聲書閣 Logo**（點擊快速返回首頁「館藏總覽」）
  2. **館藏總覽**
  3. **放映室**
  4. **語音檔案庫**（正式使用者與管理員可見）
  5. **館藏資料管理**（正式使用者與管理員可見）
  6. **系統管理**（系統管理員 `admin` 專屬，位於登入人員身分徽章左側）
  7. **登入人員狀態顯示**：
     - 精準顯示使用者在帳號管理中設定的 **「顯示名稱」** 與帳號（例如：`陳館長 (admin)`、`張老師 (teacher)` 或 `訪客模式`），不再只單純顯示系統權限代碼，讓協同管理人員一目了然。
  8. **登出按鈕**：一鍵安全清除登入狀態並返回驗證首頁。
- **行動裝置雙層次導覽列**：針對手機與直向平板，系統自動於頂部下方展開專屬次導覽工具列，支援單手大拇指快速滑動切換所有頁面。

## 四、核心功能頁面詳細說明

### 1. 館藏總覽 (`DashboardView`)

數位圖書館的首頁門面，提供全館典藏狀況速覽與直覺的木質書架陳列：

- **典藏迎賓橫幅與即時四大指標**：
  - **主題分類廳數**：全館目前已設立之分類館廳總數量。
  - **典藏語音總數**：全館已登錄收錄之語音檔部數。
  - **館藏總時長**：全館音訊內容累計之總長度（自動轉換為小時與分鐘）。
  - **雲端連線狀態**：即時顯示 Firebase Firestore 雲端資料庫與 Google 雲端硬碟的連線同步狀態燈號。
- **三欄複合快速檢索看板**：
  1. **關鍵字搜尋框**：即時比對語音檔案標題、故事與館藏說明、類別標籤、主講人姓名及分類名稱。
  2. **主講人篩選下拉選單**：自動彙整名冊中所有主講人與各自主持的作品部數，可一鍵篩選特定主講人或「未指定主講人」之語音。
  3. **類別標籤篩選下拉選單**：自動統計各分類標籤的作品數量，支援單一標籤精準過濾。
  - 檢索結果支援一鍵點擊「放映室播放」或「編輯語音」。
- **主題館藏分類廳快速導覽**：
  - 列出全部分類廳徽章（含各分類作品數量），點擊任一館廳即可**平滑捲動（Smooth Scroll）**至下方對應的木質書架。
  - 頂部工具列提供 **「開啟全部館藏隨機播放」** 按鈕與 **「新增分類廳」** 快捷按鈕。
- **各分類圖書館木質書架展示區**：
  - **索書號獨立流水編號**：系統依「館藏分類代碼 + 序號」（例如 `LIT-100-1`、`LIT-100-2`）為每一部語音自動賦予專屬索書號。
  - **主講人分佈統計徽章**：書架標頭下方自動統計該分類內有作品的主講人與作品部數，點擊徽章可直接篩選該書架之作品。
  - **獨立書架分頁切換**：每個分類書架皆可切換每頁顯示部數（4 部 / 8 部 / 12 部 / 16 部 / 顯示全部），並提供獨立的翻頁工具列，避免單一分類過多拉長畫面。
  - **書架快捷操作**：提供「**隨機播放**」、「**進入本廳放映室**」與「**在此分類上傳語音**」功能。
  - **精裝書背卡片**：封面圖片、索書號、時長、主講人姓名（清晰標示於時長與插圖數量之間）、展演插圖數量、類別標籤徽章與故事說明摘要。

### 2. 放映室 (`ScreeningRoomView`)

專為劇院級同步視聽體驗設計的核心放映介面：

- **雙欄式沉浸劇院佈局**：
  - **左側「館藏選單與播放清單區」（可隨時展開或收合）**：
    - 支援依「館藏分類」、「主講人」、「類別標籤」與關鍵字複合查詢，並支援清單分頁瀏覽。
    - **播放佇列管理**：可勾選多部語音加入待播清單，支援 **「隨機排序播放」** 與 **「自動接續播放下一首」**。
    - **已儲存播放清單（常用清單）**：
      - 可將目前勾選的播放佇列儲存命名並同步至 Firebase 雲端。
      - **選取後自動播放**：在「已儲存播放清單」下拉選單中**選取任一常用清單後，系統會立即自動載入清單並自動開始播放第一首語音檔**，無需額外手動點擊。
      - 支援隨時更新現有清單內容、重新命名或刪除已儲存的清單。
  - **右側「同步展演舞台與專業音訊播放器」**：
    - **三種展演顯示模式一鍵切換**：
      1. **圖文並茂模式**：上方展示時間軸插圖幻燈片，下方同步呈現對應時段的字幕講稿。
      2. **純插圖展演模式**：最大化展示高解析時間軸插圖與圖說，宛如實體畫冊播放。
      3. **純文字講稿模式**：提供舒適清雅的排版，隨播放秒數自動高亮目前正在朗讀的文字段落，並平滑捲動至視窗正中央。
    - **全螢幕劇院與字體縮放**：支援切換至全螢幕劇院展演、調整文字大小（小 / 中 / 大 / 特大），以及自訂插圖淡入淡出轉場效果。
    - **專業播放控制列**：
      - 播放 / 暫停、時間軸進度條自由拖曳、±5 秒快速微調。
      - **五段播放語速調整**（`0.75x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`）。
      - 單曲循環播放開關、音量調整滑桿與靜音一鍵切換。

### 3. 語音檔案庫 (`AudioLibraryView`)

深度製作、上傳與多媒體編目的專業工作室：

- **雙軌音訊匯入方式**：
  - **音訊檔案上傳**：支援 MP3、WAV、M4A、AAC、OGG、FLAC、WebM 等格式，自動讀取時長並透過 GAS 代理上傳至 Google 雲端硬碟，同時自動切割建立 Firestore `audioChunks` 音訊分片。
  - **麥克風線上即時錄音**：支援在電腦或智慧型手機上直接啟動麥克風錄製，顯示錄音波形與秒數計時，錄畢可即時試聽並一鍵發布成為典藏。
- **語音館藏多媒體編目設定**：
  - **語音檔案名稱**：修改標題後，系統會自動在背景同步將 Google 雲端硬碟上的對應音訊實體檔案重新命名，保持雲端檔名與系統名稱完全一致。
  - **所屬館藏分類**：可隨時變更所屬的館藏廳別。
  - **故事與館藏說明內容**：支援撰寫完整故事背景或導讀介紹。
  - **選取主講人**：
    - 位於封面圖正下方，提供下拉選單指派主講人。
    - 提供「新增主講人」捷徑，輸入名稱後立即建立新名冊項目並自動指派給當前作品。
  - **類別標籤設定（快速標記列）**：
    - **位於選取主講人區塊下方**，專門陳列系統正式登錄的所有類別標籤。
    - 點選標籤即可輕鬆進行多選或取消標記，提供最順暢且符合人體工學的編目動線。
- **播放時的文字顯示（SRT 字幕即時連動切換）**：
  - 支援一鍵匯入標準 `.srt` 字幕檔，自動解析序號、起迄秒數與文字內容，亦支援手動編輯或時間區段平均調整。
  - **播放秒數自動連動切換**：當在編輯器內按下語音播放（或拖曳進度條）時，**下方文字區塊會依照目前播放秒數自動高亮切換至對應的 SRT 時間區段**，並平滑捲動至視野中央；上方看板亦即時顯示目前段落字幕。點選任一時間標籤亦可直接跳轉至該秒數播放。
- **播放時的圖片顯示（多張時間軸展演插圖）**：
  - 支援**批次選取多張圖片**一次上傳至 Google 雲端硬碟。
  - 每張展演插圖皆可設定：
    - **對應 SRT 字幕段落區間**（如第 1 段至第 5 段）：系統會自動計算對應的起始與結束秒數，並自動將該區間的 SRT 字幕文字填入插圖說明！
    - 手動微調起迄秒數與圖說文字。
    - **修改圖片檔案名稱**：同步更新 Google 雲端硬碟內的圖片實體檔名。

### 4. 館藏資料管理 (`CatalogManagementView`)

全館分類、主講人名冊、類別標籤與語音檔案的維護管理中樞：

#### 4.1 館藏分類維護管理
- **分類卡片全覽**：清晰顯示排序流水號、索書號代碼、代表色標籤、代表圖示、館藏數量與分類介紹。
- **是否開啟訪客瀏覽 (`allowGuest`) 設定**：
  - 每個分類卡片上均設有「是否開啟訪客瀏覽」勾選開關與狀態標籤（`✓ 開放訪客瀏覽` / `未開放訪客`）。
  - 勾選後即時同步儲存至 Firebase，未開放的館別對訪客完全隱藏。
- **100 種主題色系 & 100 款館廳圖示**：新增與編輯分類時，提供 100 種色票與 100 款典藏圖示下拉選單（附即時預覽）。
- **排序移動與整館遷移**：
  - 支援「上移 / 下移」自由調整分類在首頁的顯示順序。
  - 支援「**移動本館館藏**」功能，將某一分類下的所有語音檔一次批次遷移至另一分類。
  - 刪除分類時具備防呆機制，若分類內仍有作品，會強制要求管理員選擇接收的新分類，確保檔案不會遺失。

#### 4.2 語音檔案館藏資料管理
- **五欄複合精準查詢**：
  - 支援同時依 **「1. 語音檔案名稱」**、**「2. 館藏分類」**、**「3. 主講人」**、**「4. 說明內容」**、**「5. 類別標籤」** 進行即時過濾。
- **多條件排序與分頁**：
  - 支援依「上傳日期」、「檔案名稱」、「館藏分類」、「主講人」進行「由大到小 / 由小到大」排序。
  - 分頁每頁支援 **10 / 20 / 30 / 50 / 100 筆** 切換。
- **卡片行內極速編輯**：
  - 無需跳轉頁面，直接在卡片上修改語音名稱（自動同步修改 Google Drive 實體檔名）、館藏分類、主講人、故事說明與類別標籤。

#### 4.3 主講人名冊維護管理
- 點擊「語音檔案館藏資料管理」區塊右上角或各卡片主講人下拉選單旁的 **「名冊維護」** 按鈕即可開啟主講人維護管理視窗。
- **統計即時顯示**：顯示全館主講人總數與「尚未指定主講人之語音檔筆數」。
- **館藏語音數篩選**：清單列出每位主講人的館藏部數，點擊部數徽章即可自動跳轉至下方並篩選該主講人的所有語音。
- **新增主講人**：支援快速輸入並建立主講人名冊。
- **原位修改與排序鎖定**：修改主講人姓名時直接在原列更新，**排序嚴格保持穩定不跳動**，且**確認修改後自動批次同步更新全館所有關聯語音檔的主講人欄位**。
- **安全防呆刪除**：刪除主講人時，若有語音檔仍指派該主講人，系統會主動提醒並自動解除該欄位，保護語音檔本體完好。

#### 4.4 類別標籤維護管理
- 點擊「語音檔案館藏資料管理」標頭右上角或各卡片快速標記列旁的 **「類別標籤管理」** 按鈕即可開啟標籤維護視窗。
- **全域正規標籤登錄機制**：卡片上的快速標記嚴格僅帶入正式登錄之標籤內容，杜絕無人維護的雜亂標籤。
- **分頁控制**：整合標準分頁列，支援以 **10、20、30、50、100** 等 10 的倍數切換每頁顯示筆數，序號依分頁自動累計遞增。
- **館藏分類下拉篩選與即時同步**：
  - 提供「館藏分類」下拉選單（包含全館與各分類廳名稱及語音數）。
  - 選取特定館別後，下方清單資料、標籤在該館別的使用筆數、未標記標籤之語音計數即時動態更新！
  - 支援「**僅顯示此分類使用之標籤**」過濾核取方塊。
- **使用情況展開清單**：點擊各標籤旁的「清單」按鈕，可展開列出正在使用此標籤的語音檔案標題、所屬館別與主講人。
- **標籤維護與全館同步**：
  - 支援新增標籤、就地修改標籤名稱（自動同步更新所有使用該標籤的語音檔案）、安全刪除標籤（自動從所有語音檔中移除該標籤），以及透過上移/下移自訂標籤在卡片上的排列順序。

### 5. 系統管理 (`SystemManagementView`)

當以 **系統管理員 (`admin`)** 身分登入時，上方工具列會顯示「系統管理」專屬按鈕，內含四大專業功能分頁：

#### 5.1 帳號管理與人員登入情況紀錄

##### 使用者帳號維護
- 完整列出系統所有使用者清單（顯示名稱、登入帳號、密碼、身分角色、建立日期）。
- 支援新增帳號、編輯帳號資料（密碼顯示/隱藏切換）、指派角色為「一般使用者 (`user`)」或「系統管理員 (`admin`)」，以及刪除帳號。
- **系統保護鎖定**：預設管理員帳號 (`admin` / `user_admin`) 受核心保護，無法刪除或降權，僅允許修改密碼與自訂顯示名稱。

##### 人員登入情況紀錄（清單與視覺化圖表分析）
即時捕捉並記錄所有人員的登入活動（包含密碼驗證成功、密碼錯誤失敗與免密碼訪客模式），提供完整的資安稽核軌跡：

1. **「清單 / 圖表」雙模式切換**：
   - 區塊標頭右上角設有清單與圖表切換按鈕，管理者可一鍵切換檢視型態。
2. **搜尋與多條件篩選**：
   - **關鍵字搜尋**：即時比對顯示名稱、登入帳號、裝置資訊或登入訊息。
   - **登入狀態按鈕**：一鍵篩選「全部」、「登入成功」或「登入失敗」。
   - **登入日期起訖日**：提供 `Date From` 至 `Date To` 日期區間精準查詢，附一鍵清除日期功能。
   - **排序功能**：支援依「登入時間」、「登入帳號」、「裝置 / 瀏覽器」進行「由大到小 / 由小到大」排序（預設為登入時間由大到小）。
   - **分頁控制**：支援以 10 的倍數（10 / 20 / 30 / 50 / 100 筆）進行分頁瀏覽。
3. **視覺化統計圖表模式（Chart Mode）**：
   - **五大核心指標卡片**：
     - **登入總次數**（當前篩選條件下筆數與全區間總筆數）
     - **登入成功次數**（含成功率百分比）
     - **登入失敗次數**（含失敗率百分比）
     - **活躍帳號數**（曾登入的不同不重複帳號數）
     - **訪客模式登入數**（訪客直接造訪之次數與佔比）
   - **每日登入次數趨勢長條圖（Daily Login Trend）**：
     - 呈現每日登入次數長條圖，柱體內部直觀堆疊綠色（成功）與紅色（失敗）次數比例。
     - 滑鼠懸停（Hover）在柱體上可浮動顯示該日之詳細登入次數、成功數與失敗數。
     - 底部清晰標示統計區間的首日與末日。
   - **24 小時登入活躍時段分佈圖（Hourly Distribution）**：
     - 直方圖呈現 00:00 至 23:00 的 24 小時登入頻率。
     - 自動計算並高亮標記系統全天之「尖峰活躍時段」與次數。
   - **人員登入次數排行（Top Users Ranking）**：
     - 依總登入次數由高至低自動排行，前三名分別授予金、銀、銅專屬榮譽徽章。
     - 呈現人員顯示名稱、帳號、身分標籤、成功/失敗漸層雙色長條圖、登入次數與最近一次登入時間。
   - **登入狀態與角色權限分佈比例**：
     - **狀態比例條**：成功率 vs 失敗率雙色進度條與筆數。
     - **角色比例條**：管理員 vs 一般使用者 vs 訪客模式三色進度條與統計。
   - **常用登入裝置與瀏覽器排行**：
     - 自動解析統計人員使用的作業系統與瀏覽器環境比例。
4. **紀錄管理與維護**：
   - 支援單筆刪除紀錄與一鍵清空全部紀錄（包含雙重確認對話框防呆）。

#### 5.2 系統登入畫面維護
- **即時預覽畫布**：即時呈現首頁登入畫面的羊皮紙卡片風格與圖文排版。
- **100 款典藏頂部圖示選取**：提供 100 款圖書館風格的典藏圖示下拉選取。
- **自訂主標題文字**：自由編輯登入畫面主標題（預設為「有聲書樓放映閣」），支援隨時恢復預設值與即時同步寫入雲端。

#### 5.3 雲端連線設定
- **Google 雲端硬碟 (Google Drive)**：
  - 內建 Google Apps Script (`google-drive-uploader.gs`) 原始碼一鍵複製功能與三步驟部署說明。
  - 設定 Web App URL 與 Google Drive 資料夾網址/ID（系統自動解析純 Folder ID）。
  - 提供 **「點此測試寫入 Google 雲端硬碟」** 功能，即時測試授權並反饋結果。
- **Firebase Firestore 資料庫**：
  - 管理 `Project ID` 與 `API Key`，確保雙向同步連線正常。
- **Firebase App Check 雲端防護**：
  - 支援綁定 Google Cloud `reCAPTCHA Enterprise` Site Key，為 Firestore API 請求附加合法身分驗證權杖。

#### 5.4 統計作業 (`PlayStatisticsPanel`)
專門為館長與管理員設計的數位館藏播放大數據統計作業：

1. **核心播放數據指標卡片**：
   - **累計播放總時數**（自動格式化為「X 小時 Y 分 Z 秒」與十進制小時）
   - **累計播放總次數**（以每次暫停、播畢或切換計算）
   - **累計播放人數**（依登入帳號不重複計算）
   - **曾被播放之館藏語音數**
2. **「清單 / 圖表」雙模式切換**：
   - **清單模式**：
     - 完整表格呈現：語音檔標題、館藏分類、主講人、類別標籤、播放次數、播放人數、播放總時數與最近播放時間。
     - 支援依播放總時數、播放次數、最近播放時間與標題進行升冪/降冪排序。
   - **圖表模式**：
     - **各語音檔播放總時數水平長條圖**：按播放長度比例渲染漸層彩色長條圖，支援分頁瀏覽。
     - **每日播放時數趨勢柱狀圖**：直方圖展示各日期的累計播放總時長，支援滑鼠懸停查看。
3. **強大多維度複合查詢條件**：
   - **館藏分類下拉篩選**（支援全館或指定單一分類廳）
   - **類別標籤下拉篩選**
   - **主講人下拉篩選**
   - **關鍵字搜尋**
   - **播放日期起迄日（`Date From` ~ `Date To`）**：支援精準查詢特定期間內的播放紀錄
   - **「僅顯示有播放紀錄之語音」**過濾開關
4. **分頁控制**：
   - 整合標準分頁列，每頁筆數支援以 10 的倍數（10 / 20 / 30 / 50 / 100 筆）自由切換。
5. **歷史紀錄維護**：
   - 支援一鍵清空播放統計日誌（附確認對話框）。

## 五、雲端串接與安全性設定指南

### 1. Google 雲端硬碟儲存設定 (Google Apps Script)
1. 以管理員登入後進入 **「系統管理 ➔ 雲端連線」** 分頁。
2. 點擊 **「複製 GAS 腳本」**（或複製專案根目錄下的 [`google-drive-uploader.gs`](./google-drive-uploader.gs)）。
3. 前往 [Google Apps Script 平台](https://script.google.com/) 建立新專案並貼上程式碼。
4. 於編輯器上方函式選取 `testDrivePermission` 點擊「**執行**」，完成 Google Drive 權限核准。
5. 點擊右上角「**部署 ➔ 新增部署作業**」，類型選擇「**網頁應用程式**」，將存取權設定為「**所有人 (Anyone)**」。
6. 將取得的 Web App 網址與您的 Google Drive 資料夾網址貼回「雲端連線」分頁並儲存，即完成雙向串接。

### 2. Firebase Cloud Firestore 安全規則 (`firestore.rules`)
專案具備嚴謹的 Schema 驗證與欄位白名單安全規則，防範越權竄改。如需重新部署安全性規則，請執行：
```bash
npx firebase-tools deploy --only firestore:rules --project soundbook-library-db
```
