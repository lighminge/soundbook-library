# 聲書閣 SoundBook Pavilion (`soundbook-library`)

一套以「**數位有聲圖書館**」為設計概念的現代化跨裝置網頁系統，整合 **Firebase Cloud Firestore (`soundbook-library-db`)** 雲端即時資料庫與 **Google 雲端硬碟 (Google Drive)** 媒體儲存空間，並支援自動化部署至 **GitHub Pages** 與 **Firebase Hosting**。

- **GitHub Pages 線上系統網址**：https://lighminge.github.io/soundbook-library/
- **Firebase Hosting 線上系統網址**：https://soundbook-library-db.web.app

## 一、系統特色與架構總覽

- **古典圖書館美學介面**：採用典藏胡桃木、羊皮紙卡片與精裝書背視覺設計，支援電腦、平板與手機響應式瀏覽。
- **雙雲端混合儲存架構**：
  - **Firebase Cloud Firestore (`soundbook-library-db`)**：即時同步所有館藏分類、語音詮釋資料 (Metadata)、時間軸圖文展演設定、主講人名冊、自訂播放清單、系統使用者帳號、登入畫面設定與跨裝置音訊分片 (`audioChunks`)。
  - **Google 雲端硬碟 (Google Drive)**：透過 Google Apps Script (GAS) 代理腳本自動儲存原始語音檔、封面圖與展演插圖，並支援在網頁修改標題時自動同步更新雲端硬碟內的實體檔案名稱，以及刪除館藏時同步移除雲端硬碟檔案。
- **跨裝置無縫播放與快取加速**：內建 IndexedDB 本地媒體快取與 Firestore `audioChunks` 音訊分片備援機制，確保在電腦、iPhone (iOS Safari) 與 Android 手機上皆能流暢播放。
- **零快取差異打包技術 (`gh-pages-cache-compat`)**：自訂 Vite 編譯器外掛，將生產環境的 JS 與 CSS 自動內嵌至 `dist/index.html` 並保留歷史雜湊資源別名，徹底解決 GitHub Pages 更新時的瀏覽器快取不匹配問題。

## 二、登入驗證與三層身分權限管理

系統啟動時會進入「**安全存取驗證（登入畫面）**」，每次載入皆自動清空帳密輸入框以防止瀏覽器自動填入，並支援三種身分角色：

| 身分角色 | 權限範圍說明 |
| :--- | :--- |
| **1. 系統管理員 (`admin`)** | 具備完整系統權限：可使用「館藏總覽」、「放映室」、「語音檔案庫」、「館藏資料管理」，並獨享上方導覽列的 **「系統管理」** 專區（管理所有使用者帳號、維護系統登入畫面圖示與標題、設定雲端連線與各館藏分類的訪客瀏覽權限）。 |
| **2. 一般使用者 (`user`)** | 具備館藏聽書與編目權限：可使用「館藏總覽」（瀏覽全部館藏分類）、「放映室」、「語音檔案庫」（上傳、錄音、編輯語音與展演圖文）與「館藏資料管理」。 |
| **3. 訪客模式 (`guest`)** | 於登入畫面點擊 **「以訪客身份直接進入（免帳密）」** 即可進入。訪客僅能瀏覽與播放**管理員已勾選「開啟訪客瀏覽 (`allowGuest`)」的館藏分類**及其語音作品；所有上傳、編輯、館藏管理與系統管理功能皆自動隱藏並受路由保護。 |

## 三、頂部圖書館導覽列設計

- **靠左對齊與一致大字體設計**：最左方品牌標誌「**聲書閣**」與所有上方功能列按鈕統一採用清晰易讀的大字體 (`text-base sm:text-lg`) 與一致圖示尺寸，並自動收合於深木色標題列底圖 (`#261A13`) 內，不會超出底圖邊界。
- **導覽列排列順序（由左至右）**：
  1. **聲書閣**（點擊快速返回館藏總覽）
  2. **館藏總覽**
  3. **放映室**
  4. **語音檔案庫**（正式使用者與管理員顯示）
  5. **館藏資料管理**（正式使用者與管理員顯示）
  6. **系統管理**（系統管理員專屬，位於登入人員左方）
  7. **登入人員身分徽章**（顯示如 `管理者 (admin)`、使用者名稱或 `訪客模式`）
  8. **登出**
- **行動裝置次導覽列**：在手機與平板螢幕下，自動於頂部下方提供專屬次導覽列，方便單手快速切換各功能頁面。

## 四、五大核心功能頁面詳細說明

### 1. 館藏總覽 (`DashboardView`)

- **數位有聲圖書館迎賓橫幅與統計指標**：
  - 即時統計並顯示「主題分類廳數」、「典藏語音總數」、「館藏總時長」以及目前連線狀態（Firebase 雲端即時同步 / Google Drive 雲端硬碟連線狀態）。
- **館藏語音快速檢索**：
  - 提供三欄複合快速搜尋：
    1. **關鍵字檢索**：即時比對語音標題、故事說明、類別標籤、主講人與分類名稱。
    2. **主講人下拉篩選**：自動統計各主講人作品數，可一鍵篩選特定主講人或「未指定主講人」的語音。
    3. **類別標籤下拉篩選**：自動彙整全館類別標籤與作品筆數，支援下拉快速過濾。
  - 檢索結果區支援直接點擊「放映室播放」或「編輯語音」。
- **主題館藏數量分佈與快速導覽**：
  - 列出所有館藏分類廳及其作品數量，點擊任一分類按鈕即可**平滑捲動定位**至下方對應的木質書架。
  - 提供 **「開啟全部館藏隨機播放」** 按鈕與 **「新增分類廳」** 按鈕。
- **各分類圖書館木質書架展示區**：
  - **索書號獨立編號**：系統自動依「館藏分類代碼 + 上傳順序流水號」（例如 `LIT-100-1`、`LIT-100-2`）為每部語音檔產生專屬館藏編號。
  - **主講人統計與快速篩選徽章**：在每個分類書架標頭下方自動統計該分類內各主講人的語音部數，點擊主講人徽章即可立即過濾該書架的作品。
  - **書架獨立分頁控制**：每個分類書架皆可切換每頁顯示數量（每頁 4 部 / 8 部 / 12 部 / 16 部 / 顯示全部）並提供上下頁翻頁工具列，避免單一分類館藏過多時拉長頁面。
  - **單廳隨機播放與快速操作**：書架標頭提供「**隨機播放**」、「**進入本廳放映室**」與「**在此分類上傳語音**」按鈕。
  - **精裝書背卡片**：每張卡片顯示封面圖、索書號、時長、主講人（位於時長與展演圖數量中間）、展演圖張數、分類標籤與說明摘要。

---

### 2. 放映室 (`ScreeningRoomView`)

- **雙欄式沉浸劇院佈局**：
  - **左側「館藏選單與播放清單區」**（可收合）：
    - 支援依「館藏分類」、「主講人」、「類別標籤」下拉篩選與「關鍵字搜尋」，並支援清單分頁瀏覽。
    - **自訂播放清單管理**：
      - 可勾選多部語音加入待播佇列，支援 **「隨機排序播放」** 與 **「自動連續播放下一首」**。
      - **雲端播放清單存取**：可將目前勾選的播放佇列命名並儲存為「常用播放清單」（自動同步至 Firebase Firestore），隨時載入、更新內容、重新命名或刪除已儲存的播放清單。
  - **右側「同步展演舞台與專業音訊播放器」**：
    - **三種展演顯示模式切換**：
      1. **圖文並茂模式**：上方展示時間軸插圖幻燈片，下方同步顯示對應時間區段的文字講稿。
      2. **純插圖展演模式**：最大化展示高畫質時間軸插圖與圖說。
      3. **純文字講稿模式**：提供舒適書卷閱讀版面，並支援隨語音播放進度自動高亮與平滑捲動至當前朗讀段落。
    - **全螢幕劇院與彈出視窗**：支援一鍵切換「全螢幕展演模式」、調整文字大小（小 / 中 / 大 / 特大）與切換插圖轉場動畫效果。
    - **專業音訊播放控制列**：
      - 支援播放 / 暫停、時間軸進度條拖曳、±5 秒快轉與倒退、播放語速調整（`0.75x`、`1.0x`、`1.25x`、`1.5x`、`2.0x`）、單曲循環播放、音量調整與靜音切換。

### 3. 語音檔案庫 (`AudioLibraryView`)

專為新增與深度編輯有聲書作品設計的工作室頁面：

- **語音檔案上傳與線上直接錄音**：
  - **選擇音訊檔案上傳**：支援電腦與手機選取 MP3、WAV、M4A、AAC、OGG、FLAC、WebM 等音訊格式，自動偵測音訊時長並上傳至 Google 雲端硬碟，同時自動切分建立 Firestore `audioChunks` 雲端音訊分片。
  - **麥克風直接錄音**：內建瀏覽器即時錄音器，支援在手機或電腦上直接按下錄音、即時顯示錄音秒數、完成後立即試聽並上傳成為館藏。
- **語音館藏完整編目與多媒體設定**：
  - **基本資料設定**：編輯「語音檔案名稱（修改後自動同步更新 Google Drive 上的實體檔名）」、「所屬館藏分類」、「故事與館藏說明內容」與「類別標籤（支援點選快速標記或自訂新增）」。
  - **語音檔案封面圖與選取主講人**：
    - 支援上傳自訂封面圖片至 Google 雲端硬碟，或一鍵套用展演插圖作為封面。
    - 在「語音檔案封面圖」正下方內建 **「選取主講人」** 下拉選單，可直接從主講人名冊中選取，或點擊旁側「新增主講人」按鈕即時建立新主講人並自動指派。
  - **播放時的文字顯示（支援 SRT 字幕檔匯入）**：
    - 支援一鍵匯入 `.srt` 標準字幕檔，自動解析每個時間區段（序號、起始秒數、結束秒數、字幕內容），亦可直接手動編輯全文講稿。
  - **播放時的圖片顯示（多張時間軸展演插圖管理）**：
    - 支援**批次選取多張圖片**一次上傳至 Google 雲端硬碟。
    - 每張展演插圖 (`PlaybackSlide`) 皆可設定：
      - **對應 SRT 字幕段落區間**（例如：第 1 段至第 5 段），系統會自動計算對應的起始秒數與結束秒數，並自動將該區間的 SRT 字幕填入插圖說明文字！
      - **手動調整起始秒數 / 結束秒數**與插圖文字說明。
      - **修改圖片檔案名稱**：修改後自動同步更新 Google 雲端硬碟中的圖片實體檔名。

### 4. 館藏資料管理 (`CatalogManagementView`)

提供全館分類、標籤、主講人名冊與語音檔案的批次與行內快速管理：

- **區塊 1：快速標記（類別標籤）管理**
  - 管理全館通用的快速標記標籤（如：`繪本`、`小說`、`童話`、`歷史`、`科普`、`詩詞` 等）。
  - 支援隨時新增自訂標籤；點擊標籤上的刪除鈕時會彈出確認視窗，可選擇刪除該快速標記並同步從所有語音檔中移除。
- **區塊 2：館藏分類管理**
  - **分類卡片全覽與排序**：顯示每個館藏分類的排序編號、索書號代碼、代表色、館廳圖示、目前館藏筆數與分類說明。
  - **是否開啟訪客瀏覽 (`allowGuest`)**：
    - 每個館藏分類卡片上均設有 **「是否開啟訪客瀏覽」** 勾選開關與狀態徽章（`✓ 開放訪客瀏覽` / `未開放訪客`）。
    - 當管理員勾選開啟後，即時同步儲存至 Firebase，訪客登入時才能瀏覽與播放該館藏分類；未勾選的分類對訪客完全隱藏。
  - **新增與修改館藏分類（100 種代表色系 & 100 款館廳圖示）**：
    - 在「新增館藏分類」視窗與每個分類的「修改」表單中，提供 **100 種代表色系** 與 **100 款館廳圖示** 下拉選單（附即時色塊與圖示預覽），以及「是否開啟訪客瀏覽」設定。
  - **排序移動與整館遷移 / 安全刪除**：
    - 支援「上移 / 下移」調整分類在總覽頁面的顯示順序。
    - 支援「**移動本館館藏**」將某一分類下的全部語音檔一次遷移至另一分類。
    - 刪除分類時，若該分類下仍有語音檔，系統會引導選擇目標分類並自動完成語音檔遷移，確保館藏不遺失。
- **區塊 3：語音檔案館藏資料管理（五欄複合查詢、主講人名冊與行內極速編輯）**
  - **五欄複合查詢與排序分頁**：
    - 支援同時依 **「1. 語音檔案名稱」**、**「2. 館藏分類」**、**「3. 主講人」**、**「4. 說明內容」**、**「5. 類別標籤」** 進行精準複合篩選。
    - 支援依「上傳日期」、「檔案名稱」、「館藏分類」、「主講人」進行「由大到小 / 由小到大」排序，以及每頁 10 / 20 / 30 / 50 / 100 筆分頁瀏覽。
  - **主講人名冊維護視窗**：
    - 點擊主講人欄位旁的「**名冊維護**」即可開啟主講人管理視窗，檢視每位主講人的館藏語音筆數（點擊筆數可直接套用篩選），並支援新增主講人、修改主講人姓名（自動批次同步更新該主講人名下所有語音檔）與刪除主講人。
  - **清單行內極速編輯**：
    - 無須切換頁面，即可在清單中直接修改每筆語音的「**語音檔案名稱**（0.1 秒寫入 Firebase 並在背景自動改名 Google Drive 檔案）」、「**館藏分類**」、「**主講人**」、「**說明內容**」與「**類別標籤**（直接點選快速標記按鈕即可增減）」，亦提供「放映室播放」與「進入語音檔案庫完整編輯」捷徑。

### 5. 系統管理 (`SystemManagementView`)

當以 **系統管理員 (`admin`)** 身分登入時，點擊上方導覽列（登入人員左方）的 **「系統管理」** 按鈕，即可切換至獨立的「系統管理」頁面，內含三個功能分頁 (Tab)：

- **第一分頁：帳號管理**
  - 完整管理系統所有使用者帳號清單（顯示名稱、登入帳號、密碼、角色權限、建立日期）。
  - 支援 **新增使用者帳號**、**編輯帳號資料與密碼**（支援密碼顯示/隱藏切換）、指派角色為「一般使用者」或「系統管理員」，以及 **刪除帳號**（附確認對話框）。
  - **系統保護機制**：預設系統管理員帳號 (`admin`) 受系統鎖定保護，禁止刪除或降級權限，僅允許修改密碼與顯示名稱。
- **第二分頁：系統登入畫面維護**
  - **登入畫面即時預覽**：左側提供與首頁登入畫面底色 (`#F6F1E7`) 及羊皮紙卡片 (`#FFFDF9`) 完全一致的即時預覽區塊。
  - **100 款登入畫面頂部圖示下拉選取**：可從編號 `1.` 至 `100.` 的精選典藏圖示中自由選取登入畫面最上方的代表標誌。
  - **自訂登入畫面標題文字**：可自由修改圖示下方的系統主標題文字（預設為「有聲書樓放映閣」），支援「恢復預設值」與「儲存設定並同步雲端」。
- **第三分頁：雲端連線**
  - **1. Google 雲端硬碟上傳儲存空間設定 (Google Drive)**：
    - 內建完整的 Google Apps Script (`google-drive-uploader.gs`) 程式碼一鍵複製功能與三步驟授權部署教學。
    - 設定 GAS 網頁應用程式部署網址 (`Web App URL`) 與 Google Drive 資料夾網址/ID（系統會自動擷取純 Folder ID）。
    - 提供 **「點此測試寫入 Google 雲端硬碟」** 按鈕，即時檢測權限並在成功後提供測試檔直接檢視連結。
  - **2. Firebase Firestore 資料庫設定**：
    - 管理 `soundbook-library-db` 專案的 `Project ID` 與 `API Key`。
  - **3. Firebase App Check (`reCAPTCHA Enterprise`) 雲端防護**：
    - 支援綁定 Google Cloud `reCAPTCHA Enterprise` 網站金鑰 (`Site Key`)，為每次 Firestore 讀寫請求附加安全驗證權杖，防範未授權存取。

## 五、雲端串接與安全性設定指南

1. **Google 雲端硬碟儲存設定**：
   - 以系統管理員登入後，進入 **「系統管理 ➔ 雲端連線」** 分頁。
   - 點擊 **「複製 GAS 腳本」**（或複製專案根目錄 [`google-drive-uploader.gs`](./google-drive-uploader.gs)）。
   - 前往 [Google Apps Script](https://script.google.com/) 建立新專案並貼上程式碼：
     1. 先選擇上方函式 `testDrivePermission` 點擊「**執行**」完成 Google 雲端硬碟權限核准。
     2. 點擊右上角「**部署 ➔ 新增部署作業**」，類型選擇「**網頁應用程式**」，「誰可以存取」選擇「**所有人 (Anyone)**」。
     3. 將取得的網頁應用程式網址 (`https://script.google.com/macros/s/.../exec`) 與您的 Google Drive 資料夾網址貼回「雲端連線」分頁並儲存，即可讓電腦與手機跨裝置共用同一個雲端硬碟資料夾。
2. **Firebase Firestore 安全規則 (`firestore.rules`)**：
   - 專案內建嚴格的 Schema 與欄位白名單驗證規則（包含 `categories`、`audioItems`、`audioChunks`、`playlists`、`speakers`、`users` 等集合之型別、長度、不可變欄位與預設管理員保護規則）。
   - 部署安全規則指令：
     ```bash
     npx firebase-tools deploy --only firestore:rules --project soundbook-library-db
     ```
